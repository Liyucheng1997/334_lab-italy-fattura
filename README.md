# 意大利开票信息卡 · Dati per la fattura

一个单文件网页工具：填写公司开票信息（Ragione sociale、P.IVA、Codice Fiscale、地址、SDI 代码、PEC 等），生成可打印的名片大小开票卡片（85×55mm）、中卡（140×96mm）或 A5 大卡，带二维码，方便在意大利购物时递给店员开具电子发票（fattura elettronica）。

## 使用

直接用浏览器打开 `fattura-card.html` 即可，无需安装。

- 信息自动保存在本浏览器（localStorage），不会上传到任何服务器
- 支持导出 / 导入 JSON 备份
- 版式：名片 85×55mm（A4 一页 10 张）、中卡 140×96mm（A4 横向一页 4 张，默认）或大卡（A4 一页 2 张）
- 卡片语言：仅意大利语，或意大利语 + 中文
- 二维码：自动生成、上传自己的图片（如税务局 Agenzia delle Entrate 官方二维码）或不显示；二维码下方文字可自定义
- 打印时请选择"实际大小 / 100%"
